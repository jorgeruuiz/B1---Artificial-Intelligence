CNNs - Basic Layers

 Input: raw pixel values. RGB image 32x32, volume [32x32x3]

 Convolutional: compute output of neurons connected to local input
   regions (each computes dot product between their weights and the
   region). Larger volume [32x32x12].

 RELU: element-wise activation function (e.g. thresholding at zero).
   Volume unchanged ([32x32x12]).

 Pooling: downsampling operation. e.g. reduce volume to [16x16x12].

 Fully-connected: compute class scores. Each neuron in this layer will
   be connected to all the numbers in the previous volume. Volume of
   size [1x1x10].

Stride, kernel size and dilation

 Stride = shift by k positions for each output
    Decreases size of output relative to input

 Kernel size = weight a different number of inputs for each output
    Combine information from a larger area
    But kernel size 5 uses 5 parameters

 Dilated or atrous convolutions = intersperse kernel values with zeros
    Combine information from a larger area
    Fewer parameters
Stride, kernel size and dilation

PyTorch and Keras use dilation = 1 for no dilation, take into account in the lab.
Output size

     Output size =  (W - K + 2P) / S  + 1

 W is the input size along one spatial dimension (width or height), e.g. 240 for a 240×240

    image

 K is the kernel (filter) size, e.g. 3 for a 3×3 kernel
 P is the padding: how many zeros are added on each side of the input. That's why it

    appears as 2P

 S is the stride: how many positions the kernel moves between outputs
 With dilation: replace K by the effective size D(K - 1) + 1. In PyTorch/Keras, D = 1 means

    no dilation

 Check with slide 16:
    (a) 8 inputs, K = 3, S = 2, P = 1: 7/2 + 1 = 4 outputs
    (c) K = 5, S = 1, P = 2: 8 outputs, so the size is kept ("same")
    (d) K = 3, D = 2 gives an effective kernel of 5

Efficient CNNs

 MobileNet (Howard et al., 2017)
    Replaces each standard convolution with a depthwise separable convolution.
    First, one K×K kernel filters each channel separately. Then a 1×1 convolution

        mixes the channels

    Used on phones and embedded devices.
 EfficientNet (Tan & Le, ICML 2019)

    Efficient way to make a network bigger: deeper, wider (more channels) or

        higher input resolution.

    Scale all three together in fixed proportions ("compound scaling") with better

        performance than much larger earlier models.
CNNs in the transformer era

 Vision Transformers: ViT (Dosovitskiy et al., ICLR 2021)

    Treats the 16x16 image patches as words in a sentence, no

      convolutions

 ConvNeXt (Liu et al., CVPR 2022)

    Implements ideas of transformers (larger kernels, better

      training recipes and fewer normalization and activation
      layers)

    Showed that most of Transformer's advantage in ViT like

      models came from training and design, not only from
      attention

Other applications 2/2

 Simulation surrogates (2D/3D fields)  Solver (LBM) vs CNN prediction and error (Guo et al., KDD 2016)

 Input: geometry on a grid. Output: steady flow field (velocity).

 CNN encoder­decoder, same idea as SegNet but with regression per pixel.

 2 orders of magnitude faster than a GPU CFD solver (4 orders vs CPU).

 Use: fast design exploration and optimization loops.

 Materials: microstructure  properties (Yang et al., Comput. Mater. Sci. 2018)

 Input: 3D microstructure image. Output: effective stiffness (regression).

 Trained on finite-element simulations, then replaces them at inference time.

 Key idea

 Simulation data lives on grids, so convolutions apply directly.

 Train once on simulations, then predict in milliseconds.
