Markov decision processes

      Markov decision processes are formal descriptions of the environment
      for reinforcement learning.
      The system is Markov  The state fully characterizes the process.
      The state is fully observable.
      Almost all RL problems can be formulated as MDPs:

           Control problems can be represented as continuous MDP.
           Partially observable processes can be modeled as belief-MDPs.
           Multi-armed bandits1 as one state MDPs.

Policies

Definition

A policy  is a distribution over actions given states,
                               (a|x) = p(at = a|xt = x)

      A policy fully defines the behaviour of an agent
      MDP policies depend on the current state (not the history)

           Policies are stationary (time-independent), except for finite-horizon
              problems, at  (·|xt ), t > 0

Utilities

      What preferences should an agent have over reward sequences?
           More or less? [1, 2, 3] or [2, 3, 4]
           Now or later? [0, 0, 1] or [1, 0, 0]

Theorem: Stationary preferences

If we assume stationary preferences:
           [a1, a2, . . .]  [b1, b2, . . .]  [r , a1, a2, . . .]  [r , b1, b2, . . .]

There is only one way to define utilities (returns).
                      U ([r0, r1, r2, . . .]) = r0 + r1 + 2r2 + . . .

Discounted utility

The utility defined as:

U ([r0, r1, r2, . . .]) = r0 + r1 + 2r2 + . . .

is called a discounted utility or discounted return, for   [0, 1).
The special case where  = 1 is called additive utility.

Why discount?

    The agent should prefer sooner
      rewards. Do not procrastinate!

    It helps convergence, specially for
      infinite horizon problems.

    Biological inspiration (human/animal).
    Uncertainty about future events.
      0 represents a myopic agent.
      1 leads to a far-sighted agent.

Infinite rewards

The utility or return of a problem must always be finite.
Finite horizon: episodes terminate after a fixed number of steps T .

                       Nonstationary policies: the action might depend on the
                       state and time step.
Discounting: use 0 <  < 1
                       Smaller  means short term focus.
Absorbing state: a terminal state that is reached for every policy.

The sequence of states from the starting state to the end (finite horizon or
terminal state) is called episode.

       episodic (terminating) task vs continuous (running forever) task

Value function

Definition

The state-value function V (x) of an MDP is the expected utility starting
from state x, and then following policy 

                                 V (x) = E[Ut |xt = x]

Definition

The action-value function Q(x, a) is the expected utility starting from
state s, taking action a, and then following policy 

                          Q(x, a) = E[Ut |xt = x, at = a]

Bellman equation for value functions

The value function can be computed recursively. The value function at any
time V (xt) can be decomposed as:

      the inmediate reward Rt+1
      the (discounted) future value function V (xt+1)

             V (x) = E[Ut |xt = x] =
                      = E[Rt+1 + Rt+2 + 2Rt+3 + . . . |xt = x ] =
                      = E[Rt+1 + (Rt+2 + Rt+3 + . . .)|xt = x ] =
                      = E[Rt+1 + Ut+1|xt = x ] =
                      = E[Rt+1 + V (xt+1)|xt = x ]

Optimal Value Functions

Definition

The optimal state-value function V (x) is the maximum value function

over all policies:

                    V (x) = max V (x)

                                      

Definition

The optimal action-value function Q(x, a) is the maximum action-value
function over all policies:

                               Q(x, a) = max Q(x, a)

                                                                  

The optimal value function is the best an agent can do in the MDP. It is
the solution.

Optimal policy

Theorem

For any Markov Decision Process:
      There is at least one optimal policy .
      All optimal policies achive the optimal value functions:
                    V (x) = V (x), Q(x, a) = Q(x, a)

Important: The optimal policy is greedy with respect to the optimal
value function.

Solving the Bellman Equations

      MDPs have all the ingredients for dynamic programming.
           Bellman equations give recursive decomposition.
           Value function stores and reuses solutions.

      We are going to see three algorithms:
      Policy evaluation: Use Bellman expectation equation.

                            1. Given a policy   compute V (x) iteratively.
      Value iteration: Use Bellman optimality equation.

                            1. Compute V (x) recursively.
      Policy iteration: Evaluate and improve a policy iteratively.

                            1. Given   compute V (x)
                            2. Given V (x), choose  greedy  compute V  (x)
                            3. . . .
                            n. Converges to  and V (x).
