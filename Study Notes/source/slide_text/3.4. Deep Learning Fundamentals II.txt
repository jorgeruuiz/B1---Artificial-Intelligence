Backpropagation (intuition)

(Rumelhart, Hinton, Williams 1986)

 Forward pass
     Perform inference from the inputs to the final function and error;
      and store activations at each node

 Backward pass
     Compute derivatives at each node using chain rule
     Trace the error backward through the chain of cause and effect,
      using local derivatives to assign precise "blame" (wLoss ) to
      every parameter.

Back-propagation computational flow

 Forward propagation can be seen as
    an acyclic flow graph.

 Each object (box) has:

    A forward function of its output depending on
       its input.

    A gradient function of its output depending
       on its input that is computed backwards.

 Software implementations are usually
    designed according to this model.

   while True:
      weights_grad = evaluate_gradient(loss_fun, data, weights)
      weights += - step_size * weights_grad # perform parameter update

 miniB SGD: gradient over batches. improve performance

 backpropagation: gradient analytically using chain rule

     gates communicate to each other what they need in order to
      increase the final output (score).

     allows to optimize relatively arbitrary loss functions (to define all
      kinds of NN, e.g. CNN)

Initialisation

 Crucial step to make the DNN converge
 If not done properly, we run into vanishing and exploding gradients
 General rule:

         No zero weights (to avoid symmetry problems)
         Controlled variance to avoid variance to compound up or down with

           depth
 Different initialisation strategies depending on the type of activation layer

     HE init for Relus,
 Biases to zero, except for some architectures such as LSTMs
Regularisation

 Why is there a generalization gap between training and test
   data?

 Overfitting (model describes statistical peculiarities)

 Model unconstrained in areas where there are no training
   examples

 Regularization = methods to reduce the generalization gap

 Technically means adding terms to loss function

 But colloquially means any method (hack) to reduce gap

    GD disfavours areas with steep gradients
    SGD favours places where the gradient is stable

 Early stopping
      Avoid weights getting too large and overfitting the result
      Reduces effective model complexity

 Ensemble (Average together multiple models)
      Take mean or median, use different initialisation and/or models

Dropout

 Clamp a random subset (typically 50%) of hidden units to zero at
   each iteration of SGD

 Training a different network each time

 Inference

    Full network: Weights adjusted to probability p of being active
      in the training (originally, in inference)

    Ensemble (monte Carlo): run multiple inferences with dropout
      active. Provides mean and variance

 Helps removing non smooth predictions far away from input data
