Self-attention (1): weighted sums
•  N inputs x1 … xN, each a D-dim vector (a frame feature, a word embedding, …)
•  Each input is mapped to a value: the same linear map for every input, no ReLU
•  Each output is a weighted sum of all the values:
•  anm: share of input m in output n, computed from the inputs (next slide)
Figures and notation adapted from S. J. D. Prince. Understanding Deep Learning. MIT Press, 2023, ch. 12 (udlbook.github.io)

=== PDF PAGE 10 ===
Self-attention (2): the weights
•  Each input also produces a query and a key (two more learned linear maps):
•  Score = key · query (similarity); softmax over m → weights of output n:
Same roles as slide 8 — query: what output n needs · key: what input m offers. New: every input is also a
query → self-attention.

Self-attention (3): a worked example
•  N = 3 inputs, D = 2, already projected. Compute output 1,
whose query is q₁ = (1, 0)
m key kₘ score kₘᵀq₁ weight a₁ₘ value vₘ
1 (1, 0) 1 0.245 (1, 0)
2 (0, 1) 0 0.090 (0, 2)
3 (2, 1) 2 0.665 (3, 1)
softmax(1, 0, 2) = (0.245, 0.090, 0.665)
•  Key 3 matches q ₁ best → input 3 dominates output 1
•  Outputs 2 and 3: same computation with q ₂, q₃ → independent →
all in parallel (matrix form, later)
Key properties
•  Parameters: only the three
projections (values, queries, keys).
They do not grow with N → any
sequence length
•  Weights are computed from the
input, not stored: a data-dependent
layer
•  Every output reaches every input
in one step
•  Order-blind: shuffle the inputs →
outputs shuffled the same way (→
positional encodings)
•  Cost: N × N scores

=== PDF PAGE 13 ===
Self-attention in matrix form
● Inputs: the N token embeddings as rows of X ∈ ℝN×D. Three learned
projections:
● QK⊤: N × N scores, every query against every key; softmax row by row → weights
that sum to 1
● Output: N × dv, each row a weighted average of the values
● Why √dk? If the components of q and k are independent with zero mean and unit
variance, q·k has variance d k. Dividing keeps the scores O(1), so the softmax does
not saturate (tiny gradients)
A. Vaswani et al. Attention is all you need. NeurIPS 2017

Positional encoding (2): fixed sinusoids
•  Why not pn = n? Unbounded. Or n / N? Depends on the length.
•  Vaswani et al.: sines and cosines at different frequencies (no parameters):
•  Each (sin, cos) pair is a clock: fast in the first dims, slow in the last
•  Works for any length; p n+k is a rotation of p n → offsets are easy to read with dot products (c)
A. Vaswani et al. Attention is all you need. NeurIPS 2017 · S. J. D. Prince. Understanding Deep Learning, ch. 12

=== PDF PAGE 17 ===
Positional encoding (3): learned, relative
•  Learned absolute: a trainable table P (Nmax × D), like the token embeddings
–  simple, but undefined beyond Nmax. BERT, GPT-2, ViT
•  Relative: what matters is the offset n − m → put it in the score
–  RoPE (rotary): rotate qn by angle ∝ n, km by angle ∝ m → qn·km depends on content and n − m. Every layer.
Llama, Mistral, Qwen
–  ALiBi: subtract a penalty ∝ |n − m| from the score (BLOOM)
Parameters Where Beyond training length Used in
Sinusoidal (fixed) none added to the input defined, limited in practice original Transformer
Learned absolute Nₘₐₓ × D added to the input no BERT, GPT-2, ViT
Rotary (RoPE) none rotates q, k in every layer better (with scaling tricks) most current LLMs
For images: 2D positions (row, column) of each patch → Vision Transformer, later
J. Devlin et al. BERT. NAACL 2019 · J. Su et al. RoFormer (RoPE). 2021 · O. Press et al. ALiBi. ICLR 2022

Causal (masked) self-attention
● Without a mask, position n would attend to n
+ 1, n + 2, … (the targets)
● Add −∞ to the scores of future positions
before the softmax:
● After the softmax those weights are exactly
0: token n only uses tokens 1 … n
● Same computation at training and
generation time → no cheating, no
mismatch
● Encoders (BERT) use no mask; decoders
(GPT) always do
attention weights with the causal mask (illustrative)
A. Vaswani et al. Attention is all you need. NeurIPS 2017 · see also Prince, Understanding Deep Learning, fig. 'masked self -attention' (ch. 12)

The cost of attention
● QK⊤ has N × N entries: time O(N2·d), memory
O(N2) per head and layer
○ RNN: O(N), but sequential. Attention: O(N2), but
fully parallel
● KV cache: when generating token by token, the
keys and values of past tokens do not change
→ store them, compute q, k, v only for the new
token
○ memory grows linearly with the context length
● Efficient attention
○ FlashAttention: exact, tiled so the N × N matrix
never sits in GPU memory
○ Sparse / sliding-window attention; linear and low-
rank approximations
○ Multi-/grouped-query attention: heads share K, V →
smaller KV cache
memory for one attention matrix (one head, one layer) if
materialised
