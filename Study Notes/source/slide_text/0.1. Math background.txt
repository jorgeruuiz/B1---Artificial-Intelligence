2 Information theory

OBJECTIVE: Revise the fundamental concepts of information theory that can be ap-
plied for machine learning, such as entropy and KL-divergence.

    Information theory provides the mathematical framework for quantifying uncertainty,
information, and the efficiency of communication. Machine learning can be seen as a form
of compression as we build models to learn patterns and predictions about probability of
occurrence. Similarly, a good compression algorithm should encode most likely patterns
with shorter codes than unlikely appearances. For example, a language-model that is
able to predict the next word is an excellent way to compress large volumes of text data.

    Concepts like entropy, mutual information, and KL-divergence help us measure
how much information is contained in data, how surprising an event is, and how different
two probability distributions are. In machine learning, these tools are fundamental: they
guide model training (e.g., cross-entropy loss), enable efficient representations of data,
and underpin algorithms in clustering, feature selection, and generative modeling.

Entropy

In his seminal work, A Mathematical Theory of Communication, Claude Shannon intro-
duce the log function as a measure of information of random variables as it have some
interesting properties (most parameters in information systems scale logarithmically, it
is monotonic, numerically stable, etc.). Intuitively, two identical memories in a com-
puter should be able to encode twice the information of a single memory. If we use
log2 the information is computed in bits, while in machine learning for convenience we
use ln = loge which measure the information in nits. Then, we can clearly see that the
negative expected information should be a measure of uncertainty, or lack of information.

Information gain

In many areas of machine learning (such as decision trees, active learning, etc.), it is
important to keep track on the amount of information that we can obtain from a set of
observations. For that, we can formulate the concept of information gain, for a random
variable X, given an observation of random variable Y which took the value y:

                            IG = KL(p(X|y)||p(X)) = H(X) - H(X|y)

If we consider the entropy to represent the amount of uncertainty, the information gain
represents the amount of uncertainty that we have removed from the system after intro-
ducing the new data point y.
